# 台灣中古車時價分析與世代通病資料庫

本專案結合 **Python 數據計算引擎** 與 **純靜態網頁儀表板**，針對台灣市售熱門車款進行跨世代殘值、車商與非第三方自售行情對比、大改款年份斷層標註、8891 等級詳細規格與單款通病深度整理。

## 核心功能

1. **多維度公信力行情對比**
   - **認證車商均價**：參考 8891 中古車實價、SUM / HOT / ABC 好車網等認證車商刊登與成交水位。
   - **非第三方民間自售實價**：參考 PTT CarShop、FB 車友社團與個人直接過戶行情（無車商管銷與保固加成）。
   - **權威車訊（天書）基準價**：台灣車商收購、銀行車貸與保險理賠標準殘值參考。
2. **大改款世代斷層與殘值異動標註**
   - 明確區分「同車名但大改款前後已非同一台車」的底盤與動力結構差異（例如 Focus MK3 乾式雙離合器 PowerShift vs MK3.5 6AT vs MK4 C2 平台 8AT、Golf MK6/MK7 DQ200 閥體災情、Civic 8/9代國產 vs 11代日本進口 e:HEV、Sentra B17 CVT 延保 vs B18）。
   - 圖表自動以垂直虛線標記 `★ 大改款年份`，並以紅色警示區間標示高風險通病年份。
3. **8891 等級詳細規格 & 單款通病調查**
   - 涵蓋每個世代、各主力動力的引擎型號、排氣量、馬力、扭力、變速箱、懸吊、油耗、尺碼與主動安全。
   - 整理單款通病好發里程、症狀、台灣預估維修費用與看車避坑重點。
4. **單年份與里程即時估價試算**
   - 依據年份新舊、行駛里程與車況等級，即時計算合理車商價、民間自售價與建議整備預留金。

## 本地執行方式（Windows .bat 一鍵啟動）

1. 直接雙擊根目錄的 **`啟動中古車分析網站.bat`**。
2. 腳本會自動呼叫 `python scripts/analyze_market.py --serve --port 8000`：
   - 重新計算並產出最新的 `data/cars_db.json`
   - 啟動本地 HTTP 伺服器並自動開啟預設瀏覽器顯示網頁。

若僅需重新計算並更新 JSON 資料檔（供 Git 提交使用），可執行 **`更新資料庫.bat`**。

## 直接掛載於 GitHub Pages

本專案採用「Python 預先產出靜態 JSON + 純前端 HTML/CSS/JS」架構，**不需要後端伺服器**即可直接託管於 GitHub：

1. 將整個資料夾推送到 GitHub Repository。
2. 前往 GitHub Repository 的 **Settings → Pages**。
3. **Source** 選擇 `Deploy from a branch`，Branch 選擇 `main`，資料夾選擇 `/ (root)` 後儲存。
4. 數分鐘後即可透過 `https://<你的帳號>.github.io/<儲存庫名稱>/` 直接瀏覽完整網站。
